# Grade 10 Lesson Plans – Term 1 (2026-27)

Live site: https://ashraf2k.github.io/g10-lesson-plans/

Open the site and choose a group from the main menu:

- **G10AM** – Computer Studies (DigiChamps Level 10, Units 2–4), classes 10/1–10/6, Weeks 7–13 (14 lessons).
- **G10BR** – Computer Science (Cambridge IGCSE 0478, Topic 8 Programming), classes 10BR1–10BR3, Weeks 7–15 (16 lessons).

Week 7 starts 4 Oct 2026. Week 14 (22–26 Nov) is the MOE autumn break, so no lessons are planned that week.

Each lesson has class checkboxes (saved in your browser). Print / Save opens the filled MRISB lesson plan form. PDFs are named like 2026-27_Computer_LP1W7_G10AM_Term1.pdf (lesson 1, week 7); LP1-LP2 files hold both lessons of a week; AllLPs files hold the whole term.

All PDF files sit in the main folder next to index.html (no subfolders).
